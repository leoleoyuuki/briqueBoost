# **App Name**: BriqueBoost

## Core Features:

- Item Acquisition Logging: Log details of items purchased for resale, including cost, condition, and source.
- AI-Powered Ad Enhancement: Enhance product listings by generating improved titles and descriptions using AI, with reasoning to create content that would attract buyers. AI tool considers initial data when generating suggestions.
- Profit Tracking: Automatically calculate and display profit margins for each item sold.
- Sales Platform Integration: Integration with sales platforms.
- User Authentication: Secure user login and registration system to manage user accounts.
- Dashboard: At-a-glance overview of key metrics like total profit, items in stock, and average profit margin.

## Style Guidelines:

- Primary color: Teal (#008080) to inspire trust.
- Background color: Light grayish-teal (#E0F8F8) to give prominence to page elements and copy.
- Accent color: Yellow (#FFDA63) for highlights and calls to action.
- Headline font: 'Space Grotesk' sans-serif for a modern, techy look.
- Body font: 'Inter' sans-serif, for clean, neutral readability.
- Use minimalist, line-based icons for clarity.
- Clean, card-based layout to present information clearly and manage complexity.
- Subtle animations to provide feedback on user interactions.
